## Inventory & Vendor Automation

**Workplace · Team project**

A scheduled workflow that validates vendor files, checks live inventory data,
routes approved movements, and returns results to the originating ticket.

**My contribution:** I built file intake and validation, connected database
checks, and implemented ticket updates that explain data issues and movements
that conflict with the system of record.

The suite supports business-rule checks, recoverable API processing, queue
conflict detection, and related asset-management workflows.

## FundTrace — AI Audit Triage

**Workplace · Applied AI · Sole creator and project owner**

I created a workflow that shortlists vendor-funding email conversations, quotes
supporting evidence, and preserves reviewer corrections.

A limited vendor benchmark shortlisted **34%** of conversations and captured
**82%** of relevant conversations, with **18%** missed. These rounded percentages
describe the benchmark, rather than expected performance on new data.

[Read the AI workflow case study →](projects/fundtrace.md)

## TurfTrigger

**Personal project · Sole project owner and human contributor**

[TurfTrigger](https://turftrigger.com) turns local conditions and regional rules
into personalized plans and SMS alerts. I used AI agents across development,
research, design, troubleshooting, and testing.

The service combines cloud integration, access controls, release verification,
completion monitoring, and workflow replay. Its supporting knowledge base
includes regional profiles, seasonal plans, product information, and safety
references.
